# Rocky Chatbot Web Application

Welcome to your Eridian Xenobiologist Chatbot! This project has been upgraded with a high-fidelity spaceship telemetry dashboard interface.

## 🚀 How to Run

1. Open this directory `C:\Projects\rocky` in your IDE.
2. In your terminal, run the development server:
   ```bash
   npm run dev
   ```
3. Open your browser to the URL displayed in the terminal:
   👉 **http://localhost:5173/**

## 🛠️ Features Included

- **🔊 Web Audio API Sound Effects**: Synthesized low-latency keyboard ticks, menu selections, and Eridian clicks.
- **🛸 Spaceship Telemetry Panel**: A mock readout exhibiting fluctuating environmental pressure sensors, acoustic metrics, and translation confidence.
- **📚 Xenobiology Field Log**: Decrypted logs about tardigrades, octopuses, house cats, and comparative biology.
- **🤖 Simulation & API Modes**: Works offline by default using a local response engine. Click the settings gear to input an Anthropic API Key and talk to the live Claude model.
